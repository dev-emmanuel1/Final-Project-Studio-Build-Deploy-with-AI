Todo List Web App

Overview:
A simple interactive Todo List web app built with HTML, CSS, and JavaScript.
Users can add, complete, and delete tasks. Tasks are saved in localStorage to persist across sessions.

Features:
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Keyboard shortcuts: Enter to add, Delete to clear completed
- Responsive, modern design with smooth animations

Usage:
1. Open index.html in a browser or run the project on Replit.
2. Add tasks and manage them with clicks or keyboard shortcuts.
